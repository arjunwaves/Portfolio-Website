Run Locally

You can run this portfolio on your local machine by following these steps.

1. Clone the repository:
   
   git clone https://github.com/arjunwaves/Portfolio-Website.git

2. Navigate to the project folder:
   
   cd Webzenith-PortfolioWebsite

3. Open "index.html" in your browser, or open the folder in Visual Studio Code and use the Live Server extension.

No backend server or package installation is required for the static website.

Deployment

This portfolio is hosted using GitHub Pages.

To deploy your own changes:

1. Push your updated files to the GitHub repository.
2. Open the repository's Settings.
3. Navigate to Pages.
4. Select the appropriate branch and root folder as the deployment source.
5. Save the settings and wait for the website to update.
